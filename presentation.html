A daily pause for mental wellbeing

A personal project exploring AI-assisted development with Claude Code & VS Code

Mental Health Awareness Month · May 2026
The idea

We spend most of our day in reactive mode

Morrow is a two-minute invitation to step out of that. It doesn't track productivity or set goals. It just creates a small, consistent space to breathe and check in with yourself.

What it does

Breathe

Guided 4-4-6 breathing with ambient sounds — rain, waterfall, birds, singing bowl.

Check in

Moon-phase mood scale before and after each session to track how you shift.

Reflect

A personal journal with guided prompts that builds quietly over time.

Grow

Weekly mood chart and daily streak — gentle progress, no pressure.

The session flow

Five steps to a quieter mind

  • Check in with your current mood using the moon-phase scale
  • Choose a focus — breathing, clarity, gratitude, letting go, and more
  • Set a session length — 1, 3, 5, or 10 minutes
  • Follow the breathing circle with ambient sound and guided prompts
  • Reflect, journal, and see your mood shift at the end
The build

Built with Claude Code + VS Code

What I used

Plain HTML, CSS, and JavaScript — no frameworks, no libraries. All audio generated with the Web Audio API. Data stored in localStorage.

What Claude Code enabled

Going from a blank page to a fully featured app — sound engine, animations, journal, mood charts — faster than I thought possible as a solo builder.

What I learned

AI-assisted development isn't just about speed. It changes what feels achievable — and pushes you to think bigger about what you can build alone.

The result

A working product I'm genuinely proud of — and a new way of thinking about personal development through building.

Roadmap

What's next for Morrow

  • Session reminders via browser notification
  • Shareable reflection cards
  • Custom colour themes
  • Mobile-optimised layout
  • Expanded focus library and longer guided sessions

A small daily practice. A reminder that slowing down is a skill worth building.
